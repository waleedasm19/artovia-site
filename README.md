# موقع مؤسسة إرتوفيا الخيرية (ACF)

موقع ثابت (HTML وCSS وJavaScript بلا إطار عمل) يعمل على أي استضافة مجانية مثل GitHub Pages أو Cloudflare Pages.

## البنية
- `tools/pages/*.html`: محتوى كل صفحة. **عدّل هنا**، ثم شغّل `python3 tools/build.py` لتوليد الصفحات في الجذر مع الترويسة والشريط والتذييل الموحّدة.
- `data/books.json`: الكتب. لإضافة كتاب: أضف عنصرًا جديدًا وصورة غلافه في `assets/img/covers/`.
  - `status`: `done` أو `wip`، و`progress` نسبة الإنجاز، و`pdf` رابط التنزيل (اتركه فارغًا حتى يجهز).
- `data/fields.json`: المجالات العلمية التسعة وألوانها.
- `data/feeds.json`: مصادر الأخبار (RSS). أضف أو احذف مصدرًا من هنا فقط.
- `data/news.json`: الأخبار المعروضة، يحدّثها `tools/fetch_news.py` آليًّا.
- `assets/`: الأنماط والسكربتات والخطوط (مستضافة محليًّا) والصور.
- `tools/planet.py`: يرسم خامات «كوكب المعرفة» برمجيًّا (رسم أصلي بلا صور خارجية).

## الأخبار التلقائية
ملف `.github/workflows/update-news.yml` يشغّل جلب الأخبار كل ساعتين، ثم ينشر الموقع.
لترجمة عناوين المصادر الإنجليزية إلى العربية: أنشئ مفتاح DeepL API (الخطة المجانية تكفي) وضعه في
إعدادات المستودع ← Secrets ← `DEEPL_API_KEY`. بدونه تظهر الأخبار الإنجليزية بلغتها الأصلية.

## ملفات PDF الكبيرة
GitHub يرفض الملفات فوق ١٠٠ ميغابايت داخل المستودع. ارفع الكتب في «Releases» بالمستودع (حتى ٢ غيغابايت للملف)
وضع الرابط في الحقل `pdf` للكتاب.

## العضوية الشهرية (مستقبلًا)
البنية جاهزة لإضافتها دون إعادة بناء: صفحة الإعدادات فيها خانة «الحساب والعضوية» معطّلة،
وصفحات الشروط والخصوصية تذكرها. عند التفعيل يُقترح: Supabase للحسابات، ومزوّد دفع يدعم الجهات غير الربحية.

## التشغيل محليًّا
```
python3 tools/build.py
python3 -m http.server 8000
```
ثم افتح http://localhost:8000
