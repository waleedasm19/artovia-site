# مجلة «المدار» — خط الإنتاج الجديد (HTML → PDF)

يحل محل قالب XeLaTeX القديم (tools/magazine/madar.sty) ابتداءً من العدد ١ بتصميمه الجديد (٢٠ صفحة).

## البناء
    pip install qrcode
    python3 tools/madar/build.py tools/madar/issue-001 /tmp/madar-001.pdf
يتطلب Playwright/Chromium (المثبَّت مسبقًا في الحاوية). `check.js` يكشف الصفحات التي يتجاوز محتواها التذييل:
    node tools/madar/check.js tools/madar/issue-001/out.html

## بنية العدد
- `pages/pNN.html`: صفحة A4 لكل ملف (`section.page`)، تُجمع بالترتيب.
- `style.css`: نظام التصميم (أعمدة، أرقام الملفات «٠١/»، اقتباسات، صناديق، ألوان الأقسام s-space/s-phys/s-tech/s-life/s-med/s-earth/s-energy/s-gold).
- `img/`: صور حقيقية بتراخيص مفتوحة من ويكيميديا كومنز + `credits.json` (يُملأ آليًّا بـ get.py).
- `art/`: رسوم أصلية (لوحة الغلاف من coverart.py، شعار المؤسسة، رسوم SVG).
- عناصر نائبة: `{{cr:file.jpg}}` = سطر حقوق الصورة، `{{qr:URL}}` = رمز QR.

## الصور
`cs.sh "بحث"` يبحث في كومنز، و`get.py "File:..." out.jpg` ينزّل نسخة 1280px مع الترخيص.
الحاوية تحصل على 429 أحيانًا: المصغّرات بعرض 1280 تعمل، والأصل وواجهة API محجوبة غالبًا. استعمل runq.sh مع queue.txt.

## قواعد التحرير
- اسم المؤسسة «مؤسسة إرتوفيا الخيرية» (ACF)، لغة محايدة بلا عبارات دينية، «إصدار خيري مجاني».
- أخبار الأسبوع (الجمعة إلى الخميس) بمصادر حقيقية، ولكل خبر QR لمصدره.
- الهيكل: غلاف، محتويات، كلمة العدد وأرقام الأسبوع، ملف العدد (صفحتان)، ٦–٧ ملفات مرقمة، تجربة، فكرة الأسبوع، السماء والألغاز، غلاف خلفي. ١٥ صفحة على الأقل.
- مواعيد السماء تُحسب بمكتبة ephem لا من الذاكرة.
